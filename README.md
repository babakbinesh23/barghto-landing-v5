# برقتو — طراحی لندینگ نسخه ۵

**A Stripe-style visual exploration for a Persian solar aggregation landing page.**

> **وضعیت:** پروژه آزمایشی طراحی و توسعه رابط کاربری است؛ ادعای استقرار عملیاتی، کاربران واقعی یا صحت تجاری ارقام ندارد.

## معرفی

این مخزن یکی از طرح‌های وب‌سایت برقتو برای معرفی تجمیع برق خورشیدی و تجربه فارسی راست‌به‌چپ است. هر مخزن یک پیاده‌سازی/نسخه مستقل از رابط کاربری را نگهداری می‌کند.

## قابلیت‌ها

- Mesh Gradient و Glassmorphism
- تایپوگرافی فارسی و طراحی واکنش‌گرا
- توضیح مراحل تجمیع و فروش برق خورشیدی
- محاسبه‌گر و فرم نمایشی

## ساختار مخزن

- `index.html` — ساختار صفحه
- `css/style.css` — گرافیک و ظاهر
- `js/script.js` — تعاملات
- `assets/solar-isometric.svg` — تصویر برداری

## اجرای محلی

پیش‌نیاز: یک مرورگر جدید؛ برای مدیریت درست مسیرها بهتر است یک سرور استاتیک محلی داشته باشید. از ریشه مخزن:

```bash
python -m http.server 8000
```

سپس `http://localhost:8000/` را باز کنید. به Build پیچیده یا Node.js نیازی نیست. تمرکز این نسخه بر زبان بصری Mesh Gradient + Glassmorphism است.

## نکات مهم

- این طرح، نمونه رابط کاربری است. اعداد، فرم‌ها و پیشنهادهای درآمدی برای استفاده عملیاتی باید به داده و سامانه واقعی متصل شوند.
- ارسال اطلاعات شخصی، انتشار آمار عملکرد واقعی یا معرفی نرخ‌های بازار منوط به اتصال بک‌اند و تأیید داده‌هاست.
- قبل از بازنشر تصاویر، فونت‌ها و منابع بیرونی، مجوز استفاده را بررسی کنید.
- این مخزن بخشی از نمونه‌کارهای توسعه وب برقتو است و پروژه `smart-energy-city` مستقل از آن است.
